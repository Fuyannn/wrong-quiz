# 错题重练（危化品安全管理）

把「在线壹佰分」2026-09-19 ~ 2026-09-21 的错题里、**错 2 次以上**的题目做成手机刷题页。

## 数据

- 来源：个人账号下 16 本「模拟练习错题本」，共 394 道次
- 去重后 **234 道唯一错题**，全部收录；其中 **94 道错 2 次以上**
- 按天看：9.21 有 82 道、9.20 有 133 道、9.19 有 73 道
- 答案由「错题重做」模式的判题结果得到，全部齐全；167 道带官方解析

## 用法

直接打开 `index.html`，或把本目录整个丢到任意静态托管上。

- 手机上用浏览器打开后，可通过「添加到主屏幕」当 App 用
- 做题进度存在本机浏览器（localStorage），不上传
- 首页「范围」可选：只练错 2 次以上 / 9.21 全部 / 9.20 全部 / 9.19 全部 / 未掌握 / 全部错题
- 连续答对 2 次自动标记为「已掌握」
